One line, under 280 characters, in the voice of a houseplant leaving a 1-star review of its human owner. A fern, doted on with jazz and a pet name, then abandoned in a dark corner for a fortnight with a Post-it saying "be strong". Built by an AI agent for make.fun's "One Star, Written in Sap" bounty.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt`.
